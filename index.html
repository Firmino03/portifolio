Sobre mim

Sou Desenvolvedora Full-Stack pelo Instituto Federal de Educação, Ciência e Tecnologia de Pernambuco (IFPE) e trabalho do banco de dados à interface com Angular • Java • TypeScript • SCSS. Meus projetos vão além do básico: autenticação com JWT e Sanctum, permissões por perfil de usuário, integração com o Mercado Pago, API REST e um serviço Java independente para agendamento com validação de conflito de horário.

Antes do código, fui designer gráfica, e isso é o meu diferencial: eu desenho e implemento a interface. No TaskFlow criei um Design System próprio e, no RangoFácil, fui responsável pelo UX/UI e pelo front-end. Cada tela que construo passa primeiro pela pergunta "isso faz sentido pra quem vai usar?".

Gosto de trabalhar em equipe: no projeto de pesquisa PIBITI/PIBIC liderei um time usando Scrum, organizei as entregas com issues e atuei como full-stack. Busco uma oportunidade como desenvolvedora Full-Stack para seguir crescendo e entregar produtos que funcionam de ponta a ponta.
